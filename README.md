# 📊 Screen Time Analysis using Machine Learning

A Python-based Data Analysis and Machine Learning project that analyzes user screen usage behavior and predicts total time waste using different regression models.

---

# 🚀 Project Overview

This project studies how:

- 📱 Mobile Usage
- 📲 Social Media Usage
- 🎮 Gaming Usage

affect overall:

> ⏳ Time Waste / Total Screen Time

The project includes:
- Data Cleaning
- Statistical Analysis
- Machine Learning
- Data Visualization
- Future Prediction

---

# 🧠 Concepts Used

- Missing Value Handling
- Feature Engineering
- Correlation Analysis
- Hypothesis Testing
- Simple Linear Regression
- Multiple Linear Regression
- Polynomial Regression
- Model Evaluation
- Predictive Analysis
- Data Visualization

---

# 🛠 Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- SciPy

---

# 📂 Dataset Features

| Feature | Description |
|---|---|
| Mobile_Hours | Daily mobile usage hours |
| Social_Media_Hours | Daily social media usage |
| Gaming_Hours | Daily gaming hours |
| Time_Waste | Total calculated screen time |

---

# 📈 Machine Learning Models Used

## 🔹 Simple Linear Regression
Analyzes relationship between:
- Mobile Hours
- Time Waste

## 🔹 Multiple Linear Regression
Predicts time waste using:
- Mobile Hours
- Social Media Hours
- Gaming Hours

## 🔹 Polynomial Regression
Captures non-linear relationship between:
- Gaming Hours
- Time Waste
